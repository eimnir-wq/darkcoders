## Restoring from the bundle

The repository itself already contains the complete history — a normal `git clone`
is all you need:

```bash
git clone https://github.com/eimnir-wq/darkcoders.git
cd darkcoders
git log --oneline
```

For offline/air-gapped delivery, the accompanying ZIP also ships
`git/git-history.bundle`, which can be cloned directly:

```bash
git bundle verify git-history.bundle
git clone git-history.bundle darkcoders
```
